# 朋友跨设备独立测试服务

Refs #88，依赖 #76 / PR #77。Node.js 24 + 内置 SQLite，无新增数据库依赖。原 GitHub Pages 同机原型不替换；此服务同时提供独立测试页和同源 API。

## 本地启动

```sh
npm ci
npm run setup:assets
npm run build:gifts
npm run start:gifts
```

打开 http://127.0.0.1:4190/ 。创建后展开“分享给朋友”，将邀请交给另一个浏览器；接受后分别持有两个凭证。已有浏览器可以从“我的心意”找回。两个独立浏览器上下文测试：`node prototypes/live-gift/qa-cross-device.mjs`（使用独立临时数据库与 4191 端口，结束删除其模拟数据）。它验证网络接口与持久化，不代替两台真机公网验收。

## 数据边界

- 心意创建后保存整整 7 天，留言不延长；运行中每分钟以及访问/启动时清理，到期立即不可读。停机时清理延后到启动，磁盘由服务用户保护。
- 发送者确认后可以删除整份，包括留言、纪念、凭证散列与操作记录；接收者不能整份删除。不做内容备份。删除不能恢复，恢复代码不能恢复数据。
- 只保存这份交流，不上传个人成长、触摸轨迹、摄像头或其他聊天。称呼不用于验证身份；不同浏览器凭证不等于真人实名认证。
- 邀请在 URL fragment，页面读取后移除；没有第三方脚本或外链统计。首次明确接受者绑定接收浏览器，打开/预览链接不认领。不要公开散发邀请。
- 访问凭证保存在当前来源的 localStorage。清理站点数据、换浏览器后不承诺找回；私密浏览关闭后可能丢失。不要把浏览器存储/调试信息当作普通邀请分享。
- 每份 100 条留言（含原赠言）、300 个变更、256 KiB 状态数据；每段 80 个 Unicode 字符、称呼 20 个字符。服务器最多 1000 份活跃心意、每小时 100 次创建、单连接来源每分钟 120 次 API 请求。服务器不信任代理传来的 IP；代理层另行按真实来源限制，小规模测试时所有代理用户共享后端限额。
- 全局版本冲突拒绝写入，前端保留文本；共同确认不会自动重放。临时断网可以显式重试同一个操作 ID，已提交操作不会重复。

## 腾讯云部署

2026-09-23 核对修正：用户只确认域名在腾讯云购买，尚无已确认的云服务器；网站响应头显示 EdgeOne。以下是 **Node/SQLite 有持久磁盘时的备选部署说明**，不是要求购买服务器。优先评估 CloudBase 托管函数与事务数据库，实际套餐、备份删除规则和账号资源尚待核实，详见 [部署评估](../../openspec/changes/cross-device-gifts/design.md#hosting-verification--2026-09-23)。当前代码不能直接作为云函数上线。

若最终采用有持久磁盘的服务，独立域名及 HTTPS 入口待核对，不猜测生产目录。确认现有主站配置后，使用一个独立测试来源，例如 `https://friends-test.<已有域名>`；不替换现有根站点。

1. 本地在确定源提交运行检查及 `npm run setup:assets && npm run build:gifts`。上传项目中的 `services/gifts/*.ts`、`prototypes/live-gift/{shared-state,temperaments}.ts`、`outputs/gifts/site/` 和根 `package.json` 至独立版本目录。后端只使用 Node 内置模块，渲染类型引用运行时擦除，不需要上传 node_modules。
2. 现有服务器需 Node.js 24；为测试服务单独建立低权限系统用户、数据目录和版本目录。不能将数据库放在静态目录中，数据目录不挂在 Nginx 下，也不纳入常规网站备份。服务器磁盘快照若包含数据，须先调整备份范围再承诺删除期限。
3. 将 `xiaoying-gifts.service.example` 复制为实际服务配置，填入确定的独立 HTTPS 来源和目录。服务只监听 loopback，防火墙无需开放 4190。
4. 用 `nginx.example.conf` 加一个独立虚拟主机，使用该域名有效证书；先运行 nginx 配置检查，再平滑加载。不重启/替换正式站服务。
5. 公开前运行 `GET /api/health`、两隔离浏览器收发/刷新、重启同一测试服务后读取、错误凭证、过期/删除测试，并记录源码 SHA、静态产物 SHA、操作者和 URL。最后用两台真机实测。

环境变量：`PUBLIC_ORIGIN`（无结尾 /，必须与用户地址一致）、`PORT`（默认 4190）、`HOST`（默认 127.0.0.1）、`GIFT_STATIC`（静态产物）、`GIFT_DB`（数据库文件）。API 不提供跨域访问；不要直接让旧 Pages 页面连接此服务。

回退：保留前一版本代码/产物，停止测试服务后切换版本目录再启动；数据库保持原位，当前 schema 首版不做破坏迁移。首次部署无前一版本，可停用独立虚拟主机和测试服务；正式站与 Pages 演示不受影响。不得为了回退恢复已删除或到期的交流备份。

## API

- `POST /api/gifts`：浏览器先保存 owner/invite 凭证，再提交原文与称呼；同 owner 同内容重试找回同一份。
- `POST /api/gifts/:id/claim`：主动接受，提交邀请和独立接收凭证；同接收凭证可重试。
- `GET /api/gifts/:id`：Bearer 凭证读取自己可见的状态；不返回服务器凭证字段。
- `POST /api/gifts/:id/actions`：Bearer + revision + op + action。角色与时间以服务端为准。
- `DELETE /api/gifts/:id`：仅发送者授权。

所有写请求要求同源 Origin、JSON（DELETE 无 body）、8 KiB 上限；读取不缓存。没有日志正文、令牌输出或公共查询列表。
