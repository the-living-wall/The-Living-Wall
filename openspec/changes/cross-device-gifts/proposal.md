# Proposal

## Why

当前 #77 只能同页切换身份，刷新清空，不能让两个朋友真正交流。用户已批准腾讯云独立测试服务、保存 7 天、发送者删除整份心意，Refs #88。

## What Changes

- 免注册创建心意与一次性接收邀请，接收者明确接受后绑定独立浏览器凭证；打开链接不自动认领。
- 服务端保存对话与共同选择，每份心意固定入口；页面轮询并在刷新后恢复。
- 服务端验证角色、同一版本双方确认、重复请求、容量限制及过期删除。
- 原个人成长保持本机隔离；无 AI、账号、站外通知或生产首页替换。

## Capabilities

### New Capabilities
- `cross-device-gifts`: 独立测试环境中的免注册双方权限、持久交流、共同确认和数据生命周期。

### Modified Capabilities
无。复用尚未归档的 shared-shaping-prototype，原内存演示可继续运行。

## Impact

后续以用户截图确认的 `the-living-wall` 独立个人版、自带共享文档数据库为实际目标；已有云函数/文档适配包，未部署验收。不再采购 PostgreSQL/MySQL，也不使用 `ai-future-letter`。原 SQLite 服务保留为本地验证基线，部署操作见 services/gifts/cloudbase/README.md。

依赖 #76 / PR #77 的原型组件与 reducer；已完成的本地实现使用 Node.js 24 + SQLite 独立服务及前端联网适配、测试、运维说明。2026-09-23 用户澄清仅确认在腾讯云购买域名，不能假定已有云服务器；网站公开响应头为 `Server: edgeone makers`，尚未进入账号核对项目配置。部署候选改为优先评估托管函数与事务数据库，具体资源、费用及备份保留待核实，不创建收费资源。SQLite 仍用于本地验证，不代表可直接部署到无持久磁盘的云函数。部署与实际手机体验分别验收。

## 本轮接入验证 · 2026-09-23

复用已购 CloudBase，通过官方 Web SDK 调用独立的业务函数入口，先做隔离预览和本地协议验证，不切换生产或现有 HTTP 测试站。浏览器免注册的产品体验保持；SDK 匿名会话仅用于平台调用授权，不持久化到心意、不赋予对话角色。数据库、清理函数仍禁止客户端直接访问。现有主站核验见 docs/qa/2026-09-23-cross-device/existing-site-integration-v1/README.md；CloudBase 自定义域名的备案资源条件不再作为通用依赖。
