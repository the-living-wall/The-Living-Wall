# Spec Delta

## Purpose

让一份心意连接两个不同设备上的朋友，以免注册但权限隔离的方式保存来回留言与双方主动确认的共同经历。此能力用于独立测试站，不改变个人成长档案，不把聊天频次转化为关系评分。

## ADDED Requirements

### Requirement: 免注册的双方权限
系统 SHALL 为发送者与接收者使用独立不可猜测的凭证，显示称呼不能赋予权限。邀请必须明确接受才认领，首位接受者绑定浏览器；已认领链接不能供第三方读取对话。发送者持有的凭证不能作为接收者作出共同确认。

#### Scenario: 链接预览与伪造身份
- **WHEN** 扫描器打开邀请、第三方猜测地址，或发送者提交伪造的接收角色
- **THEN** 不认领邀请、不泄露对话、不允许冒充对方确认

### Requirement: 可靠留言与刷新恢复
系统 SHALL 持久保存心意、来回留言及共同状态，一份心意使用固定 ID。用户可在原浏览器找回；断线保留未发送正文，重复请求不会多写一条消息。页面可见时每 3 秒同步，无站外通知。

#### Scenario: 两设备和服务重启
- **WHEN** 电脑创建，手机接受并回复，然后双方刷新且服务重启
- **THEN** 相同浏览器凭证仍可读取已确认保存的消息，网络失败不显示发送成功

### Requirement: 同版本双方共同确认
系统 SHALL 在服务端复用共同塑造规则并强制不同权限凭证确认同一版本。改选、拒绝、撤回、恢复与取消纪念保持 #76 的快照规则；聊天、抚摸不自动改变共同性情。

#### Scenario: 并发与旧版本
- **WHEN** 旧方案被确认或同一请求被重发
- **THEN** 不覆盖当前结果、不重复新增纪念；版本冲突提示刷新确认，不丢失待发文字

### Requirement: 七天保存和删除
系统 SHALL 从创建时起保存 7 天，不因留言延长。到期不可再读取，运行服务应在一分钟内清理到期数据；发送者可明确确认删除整份心意，包括对话、纪念、凭证与请求记录。称呼修改不改历史快照。清除浏览器数据后不提供身份找回承诺。

#### Scenario: 到期与删除
- **WHEN** 心意到期或发送者确认删除
- **THEN** 双方不能再读取，数据库不保留原文；接收者不能删除整份心意

### Requirement: 独立测试保护与容量限制
系统 SHALL 不上传个人成长档案、不记录凭证明文或留言日志，不允许未认证读取。每份最多 100 条消息、300 个成功变更及 256 KiB 状态数据、单段 80 字及称呼 20 字；请求体、创建量和请求频率有上限。联网界面说明保存期限并移除模拟身份切换。腾讯云测试服务和数据库与正式站隔离。

#### Scenario: 超限与原站隔离
- **WHEN** 请求超限、无凭证或其他站点试图写入
- **THEN** 返回明确拒绝，原有状态不变，个人成长档案不被修改

### Requirement: 分享操作与实际状态清晰区分
系统 SHALL 在心意创建后直接展示复制邀请链接入口，说明用户仍须把链接发给朋友；不得将创建或复制称为已送达。复制失败时提供明确说明和手动复制完整邀请链接的入口。仅在服务端返回接收者留言后显示朋友已回复，不展示已读未回或催促回复。

#### Scenario: 复制邀请而非地址栏
- **WHEN** 发送者创建心意并复制邀请链接
- **THEN** 无须展开分享区即可操作，成功提示下一步粘贴给朋友，复制失败不显示成功且可手动复制包含邀请凭证的完整链接

### Requirement: 可隔离验证的官方 SDK 入口
系统 SHALL 支持显式选择官方 CloudBase SDK 传输，原 HTTP 测试入口继续独立使用。SDK 会话不代替业务凭证、不写入个人成长或共同记录；SDK 入口必须取得平台 context 提供的调用者并验证业务凭证，不能信任请求数据中的身份和来源。缺失配置或平台授权时明确拒绝，不默默改用其他传输。

#### Scenario: 伪造平台调用者与跨心意凭证
- **WHEN** 无平台会话的请求伪造 event 中的用户信息，或匿名会话使用其他心意的凭证
- **THEN** 请求被拒绝，不返回留言、不改变记录，数据库和清理函数仍不对客户端开放

#### Scenario: 超时和平台错误
- **WHEN** 平台返回限流、认证错误、非 JSON 内容，或写入已完成但响应超时
- **THEN** 界面显示明确失败或待重试，保留原输入与未确定结果的操作 ID；相同请求重试不产生重复心意或留言

#### Scenario: 选择 SDK 的预览构建
- **WHEN** 使用 SDK 构建预览而生产仍使用现有构建
- **THEN** SDK 只在业务操作时加载，构建要求显式的环境、地域和专用函数配置，不改变现有 HTTP 来源规则、正式站或个人成长行为
