# Design

## Context

见 proposal.md。#77 的 SharedExperience 接收 reducer dispatch，SharedState 管共同选择。GitHub Pages 仅静态托管；本地新版本由独立 Node 服务同源提供页面/API。用户尚未确认拥有云服务器，不能再以获取 SSH 作为必然部署前提；公网承载方式待托管能力、费用和数据生命周期核实后确定。

## Goals / Non-Goals

**Goals:** 复用状态规则，事务、版本检查、幂等写入。本地使用单实例 Node.js 24 内置 SQLite；公网优先评估免服务器维护的托管方案，不把本地数据库零服务费推断为上云零费用。
**Non-Goals:** 账号、真实人物认证、通知、多机集群、线上个人成长迁移。原 Pages 原型不替换。

## Decisions

- 新增独立服务，SQLite 文件放静态目录之外，权限仅服务用户可读。WAL 不用于备份；secure_delete 开启，删除/过期清理所有关联记录，不建立内容备份，日志不记录 body/token。
- 随机 256 位发送/邀请/接收凭证；服务端只保存散列。发送者令牌由浏览器预生成并持久保存，使创建响应丢失可幂等恢复；接收者也先保存自己的令牌再显式认领，可重试同一认领。角色始终从认证推导，忽略请求的 actor，服务端生成确认时间。
- 邀请放 URL fragment，落地即从地址栏移除并暂存本机；GET 不认领、不提供正文。邀请只能一次认领，但同一接收凭证可安全重试。发送者保留可复制邀请，提示仅发给一位朋友；这不是实名验证，不能防本人另开浏览器接受自己的邀请。
- 写入带操作 ID 和全局 revision；重复同负载返回当前状态，不同负载拒绝；冲突返回 409，界面保留正文与当前提议供重新确认。不自动重放共同确认。
- 初次发布后原赠言不再编辑，后续通过追加留言表达；不实现单条删除，发送者可删除整份。显式双重确认删除。
- 固定创建日起 7 天；启动、访问、分钟清理到期记录；单份 100 消息/300 变更/256 KiB 状态数据，服务最多 1000 活跃心意、每小时最多 100 次创建；单 IP 每分钟最多 120 API 请求。不信任外部 X-Forwarded-For，反向代理另行限流。
- 同源、Bearer 头、no-store、无第三方脚本、Referrer-Policy no-referrer；JSON 写接口校验 Origin、Content-Type、8 KiB 请求体。静态仅白名单产物，不暴露源码/数据库。隐藏页停止轮询，恢复后同步。

## Risks / Trade-offs

- 凭证被复制可冒用 → 提示不要分享管理凭证；localStorage 只限独立测试来源；无找回服务。
- SQLite 单实例吞吐有限 → 小范围测试容量限制，扩大前重新设计。
- 删除无法撤销 → 用户确认，测试站不备份对话；代码可回退但数据不回滚。
- 服务器访问未配置 → 先用隔离浏览器和持久数据库完成本地验证，交付启动/反向代理配置；有入口再上云，不声称已跨公网可用。

## Migration Plan

独立测试项目和 HTTPS 来源，不替换生产根路径。单实例 Node/SQLite 的启动配置保留为备选，不应用到未确认的服务器。若选择托管函数，先适配事务存储、过期清理、分布式限流及运行时，再重新验证；不能使用函数临时磁盘保存长期数据。首次发布无旧数据；失败停用测试服务，原 Pages 演示继续。正式部署需记录环境、源提交、产物校验、重新启动或函数实例切换验证和回退版本。

## Hosting verification · 2026-09-23

用户后续截图确认：独立环境 `the-living-wall` 为个人版，环境 ID `env-d1g2bv5sn355fc36e`；文档数据库自带共享实例 `tnt-4tn13ikbi`，集合列表为空。MySQL 页面尚未开通，实际环境不能按 PostgreSQL 假定。采用已有文档数据库与普通云函数，不新购数据库或服务器，不触碰另一个项目 `ai-future-letter`。

云端存储把单份心意、权限散列、状态和幂等摘要保存在同一文档；事务内执行认领、版本校验和状态提交。独立配额文档跨函数实例限流及计数；全站每分钟 120 次请求是小范围测试上限。定时清理函数与 HTTP 函数分开，清理函数不提供公网入口。集合禁止客户端直接读写，所有业务通过后台验证。运行时 SDK 固定版本，云端不依赖 node:sqlite。页面/API 仍通过独立同源入口提供，网关及自定义域名配置必须实际验收。

页面提示回档未开启，只证明未启用该功能，不等于物理副本保留已核实。公开真实留言前仍需核实云服务的数据删除边界。

- EdgeOne 官方提供 Cloud Functions 和免费额度，但当前账号套餐、项目地域、余量与权限未核实。官方文档列出的 Node.js 运行时为 20.x，本地 `node:sqlite` 服务不能直接搬入；文件不应作为长期存储。[函数文档](https://pages.edgeone.ai/document/cloud-functions)、[额度](https://edgeone.ai/document/211893332490612736)。
- CloudBase 云函数与文档数据库作为优先候选，可在同一测试环境完成后台和数据访问，避免额外跨平台管理密钥。[服务端事务](https://docs.cloudbase.net/database/transaction) 支持事务一致性；仍需对认领、版本检查及重复请求逐项验收。
- 公开个人版限时优惠为 19.9 元/月，并有新用户体验活动；这不是最终账单或费用上限，需核对实际账号及额外用量设置。[价格](https://cloud.tencent.com/document/product/876/75213)、[产品页](https://cloud.tencent.com/product/tcb)。
- [数据库回档文档](https://docs.cloudbase.net/database/backup) 说明自动备份及默认 7 天备份保留；价格表的个人版未列回档能力，不能由此推断没有备份。必须核实能否满足既定删除承诺；若不能，先展示“到期不可访问”和“备份何时清理”的差别，请用户决定，不默默延长数据保留。
- 控制台浏览器连接超时，仅核实了公开文档和网站响应头；未核实账号资源、未购买、未部署、未上传真实留言。

## First cloud test deployment · 2026-09-23

上述“尚未部署”属于部署前记录；现已在该独立环境部署源 7e30d0b，三场景和九项真实云接口检查通过。用户明确同意最小测试入口：两台设备先确认默认首页的腾讯云访问提示，再打开邀请链接；首次直接开邀请会丢失 fragment，失败证据不改写。此临时路径仅用于虚构内容联调，不取消一次点击直达、静态安全响应头、备份清理和真机验收要求。回档 API 返回可用时间范围，最终物理备份保留仍未知；主站不变，Draft 保留。环境、限流、权限、部署失败及回退见 [部署记录](../../../docs/qa/2026-09-23-cross-device/cloud-first-deploy/README.md)。
