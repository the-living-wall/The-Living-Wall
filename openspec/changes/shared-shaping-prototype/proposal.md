# Proposal

## Why

用户希望在朋友互动模块中，由两个人主动选择并共同确认，使一份心意中的小莹形成性情与共同记忆。当前原型只有单条本页回声，没有预览与正式生效的区分，也没有共同决定的可体验流程。

Refs #76；依赖 #69 / PR #70。此变更验证交互方向，不代表跨设备通信或真人身份验证。

## What Changes

- 在现有赠光原型接收视角中加入两位模拟参与者、来回留言及片段选择；明确同机演示、刷新清空。
- 统一「一起塑造小莹」入口：选取对话后默认保留现有表现，亦可选择沉静、俏皮、好奇；共同确认后保存纪念及可选的样子变化。
- 预览只影响当前试看的表现；提议需另一体验身份确认当前版本后生效。改选会清除旧确认；拒绝、未回应、撤回不会改变现状。
- 新增三套持续可见的 v2 动作/光感表现，普通互动中保留特征，休息、受惊、恢复及减少动态时静态呈现；旧 v1 保持不变。
- 保留选择的来由、双方确认、原表现和固定表现版本；允许再次提出调整、恢复之前的表现或取消一条纪念，仍经双方确认。
- 不接入 AI、后台、通知或身份识别；SH-10～12 保持待办，不修改生产路由及真实成长档案。

- 整合开头、正文和双方可选称呼；保护自定义文字，称呼贯穿交流并在共同记录中保存快照。
- 朋友创作与接收页移除成长大面板，以共同经历为主；个人陪伴界面和成长机制不变。

## Capabilities

### New Capabilities

- `shared-shaping-preview`: 本地共同性情与记忆的选择、预览、双方确认、撤回、版本记录和表现隔离。

### Modified Capabilities

无。现有主规格仅有 recording-batches；成长阶段与普通声音行为不变。

## Impact

- 主要修改 `prototypes/live-gift/`，新增独立状态逻辑、表现目录与测试，复用现有渲染器但不改变其生产调用行为。
- PRD CO-01～08 和需求决策记录同步本地原型状态；新增测试接入现有测试命令。
- 独立 worktree 和端口 4180，不替换正在运行的 4179 预览。上层 Draft PR 暂依赖 #70；底座合入后本任务将 base 调回 main 并重新验证。不自动合并或部署。
