# 主前端深度实验

## Purpose

允许用户在本机主前端使用已连接的真实深度相机测试原版碎光的视觉反应，清楚区分实验性近墙区域与真实手部触摸，并在输入失效时停止互动，防止旧位置继续触发行为。

## ADDED Requirements

### Requirement: 单分支可复现测试
仓库 SHALL 包含与前端适配协议匹配的深度服务源码、依赖清单及本机启动说明，不依赖作者的临时目录。普通前端测试 SHALL 不要求安装深度 SDK。

#### Scenario: 同伴首次拉取
- **WHEN** 同伴拉取实验分支并按说明安装依赖
- **THEN** 可启动普通前端；在支持的硬件环境另建 Python 环境后，可启动匹配的相机服务，无需复制作者的虚拟环境。

### Requirement: 主动选择深度实验
系统 SHALL 在本地开发主前端提供深度测试入口，保留原版视觉渲染，并使深度、RGB、鼠标输入互斥。生产页面 SHALL 不提供本地深度接口。

#### Scenario: 切换输入
- **WHEN** 用户开启深度测试
- **THEN** RGB 采集停止，鼠标和方向键不再生成互动输入，原版碎光继续显示。

### Requirement: 有效区域映射
系统 SHALL 仅接受真实相机模式中有效、已校准、帧龄不超过300毫秒的最大近墙区域；中心必须是0至1范围内的有限坐标。系统 SHALL 支持水平及垂直镜像，并显示输入位置与实验状态。

#### Scenario: 真实区域移动
- **WHEN** 有效近墙区域的位置变化
- **THEN** 映射位置进入原版行为模型，近墙作为实验互动条件，界面不声称识别出手掌或确认物理触摸。

### Requirement: 失效与校准状态
系统 SHALL 在无区域、未校准、正在校准、无效数据、请求失败或输入超过300毫秒未更新时清除互动位置，不自动切换模拟。校准中 SHALL 显示校准状态而非泛化错误。

#### Scenario: 失去有效输入
- **WHEN** 原先存在区域但现在断流或区域消失
- **THEN** 停止输入，原版碎光执行自己的离开反应，不继续沿用旧点。

### Requirement: 实验存档隔离
系统 SHALL 使用独立本机实验成长档案并保留普通模式原档案；退出深度实验 SHALL 恢复普通模式档案。

#### Scenario: 完成深度实验
- **WHEN** 用户关闭深度测试
- **THEN** 普通模式成长不受本次实验影响，鼠标互动恢复。
