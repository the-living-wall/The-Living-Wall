# Design

## Context
7faf764 中单声道抢占与顺序播放阶段导致素材可试听、互动却难出现。

## Goals / Non-Goals
仅修改声音与验证。保持 Creature 行为、绘制、成长及相机参数。

## Decisions
- 渲染朝向 heading 角速度区分快转和持续旋转（0.65/1.8 rad/s，持续 0.35 秒）；位移用 motionSpeed。常态粒子缓慢自转不配声。
- 核心短声、持续呼噜、旋转/鳞片、移动四个通道；受惊清空全部，普通动作可同帧出现。
- 享受阈值与 UI 一致 0.45，不再等待前面的回应；有效接触内 0.8 秒换向余量，接触丢失立即结束。
- 恢复已有 scales.mp3 和 move.mp3；移动截取前一秒。原文件保留，维持低呼噜和低接触音量。

## Risks / Trade-offs
- 多通道叠加 → 实测输出峰值、停止行为与音频加载。
- 自动化不等于听感验收 → 保留用户本地试听，不发布。
- 基于用户指定旧分支实验 → 正式 PR 前另需整合最新 main 并重新验证。
