# Design
## Context
参见 proposal.md。现有 Creature 提供情绪与呼吸，网页尚无声音；五个 Freesound 音效及指定 Pixabay 原曲已取得。
## Goals / Non-Goals
目标是离散状态回应和独立音乐；不新增麦克风、身份识别、云端成长。
## Decisions
- 纯状态调度器检测边沿、冷却与持续抚摸时长，音效不循环、不累积队列。比每帧按状态播放更有留白，也能独立测试。
- 只暴露现有有效抚摸布尔值，不重复推导接触条件。重置后清除旧音效。
- Web Audio 短片段限时、低通、减速、有限延迟尾音；一条短音效通道，音乐用独立媒体元素以控制内存。
- 浏览器首次点击才初始化；加载可取消、超时可重试。后台停止短声、暂停音乐，返回通过按钮恢复，避免移动端自动播放失败。
- 素材与源码许可分开，音乐仅用于互动作品背景，不作为音频库提供下载。
## Risks / Trade-offs
- 手机扬声器低频弱 → 保持独立音量，真人试听再调参数。
- 浏览器启动策略不同 → 所有开启由点击触发并处理播放失败。
## Migration Plan
PR 检查通过后合入 main，构建腾讯静态产物并发布；保留上一部署可回退。无需存档迁移。
