# Design
## Context
参见 proposal.md。现有 Creature 提供情绪与呼吸，网页尚无声音；五个 Freesound 音效及指定 Pixabay 原曲已取得。
## Goals / Non-Goals
目标是离散状态回应和独立音乐；不新增麦克风、身份识别、云端成长。
## Decisions
- 纯状态调度器检测边沿、冷却与持续抚摸时长，音效不循环、不累积队列。比每帧按状态播放更有留白，也能独立测试。
- 只暴露现有有效抚摸布尔值，不重复推导接触条件。重置后清除旧音效。
- Web Audio 短片段限时、低通、减速、有限延迟尾音；一条短音效通道，音乐用独立媒体元素以控制内存。
- 浏览器首次点击才初始化；加载可取消、超时可重试。后台停止短声、暂停音乐，返回通过按钮恢复，避免移动端自动播放失败。
- 素材与源码许可分开，音乐仅用于互动作品背景，不作为音频库提供下载。
## Risks / Trade-offs
- 手机扬声器低频弱 → 保持独立音量，真人试听再调参数。
- 浏览器启动策略不同 → 所有开启由点击触发并处理播放失败。
## Migration Plan
PR 检查通过后合入 main，构建腾讯静态产物并发布；保留上一部署可回退。无需存档迁移。

## #59 运动声音补充
使用渲染器已有 heading 的最短角差/时间检测转身速度，1.2 rad/s 进入、0.65 rad/s 退出，忽略超过 0.25 秒的帧间隔。受惊边沿/frightCount 增量立即抢占，单次短声最多 1.2 秒；快速转动每 1.3 秒最多触发一次，放缓淡出。运动期间跳过抚摸序列，恢复后重新计时，不补播过期回应。鳞片增益 0.32、低通 2800Hz、减速 0.6，保留纹理而非低频闷响。

## #61 完整音效链路
五份音效加一首独立音乐。有效触碰播放 touch；抚摸约 1 秒 voice（Cute Creature），约 4 秒且 enjoyment > 0.45 播放 3 秒 purr，约 8 秒且 enjoyment > 0.65 播放 roll；运动优先规则沿用 #59。touching 只暴露已有接触区域/速度门控，在有效接触区允许 0.5 秒换向停顿，不允许悬停凭空推进阶段；长停顿/离开结束序列。音频引擎将单声部 busy 反馈给调度器，避免丢弃声音却已推进阶段。voice 截去原素材尾部静音，保留有限回声尾音。

翻动声从原素材 0.5 秒处截取，低通 3500Hz、增益 0.4，避免首段过轻导致感知不到；实际浏览器音频输出逐项测量，真人音色和音量偏好仍待反馈。
