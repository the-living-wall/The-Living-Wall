# 设计

## 数据边界

仓库只保存文本目录、脚本和经过授权的派生素材占位说明。创作者原始 WAV 位于仓库外的私有目录；处理脚本默认要求显式输入和输出路径，并支持 dry-run。

## 音频链路

`creator WAV -> 校验/裁剪/响度 -> 变速/变调/滤波变体 -> 空气/颗粒/谐波层 -> 本地移动端素材`

声音表达是 2–3 个音素的组合。变体可以改变音高、时长和纹理，但不能改变事件语义。引擎在播放前检查冷却与优先级，受惊、休息和拒绝可以中断低优先级表达。

## iOS 边界

`XiaoyingVoiceEngine` 只接受 `VocalGesture`，不接受文字；实现使用 AVAudioEngine、AVAudioPlayerNode、TimePitch 和 EQ。AR 层负责把放置、移动、倾斜、邀请和休息映射为音素事件，音频初始化失败时返回静默结果。

## 验证

纯组合和冷却逻辑在 Swift XCTest 与 TypeScript 测试中覆盖；ARKit 真机、耳机/扬声器和 5–8 人听感测试属于设备/人工验收，不在 CI 中伪造通过。
