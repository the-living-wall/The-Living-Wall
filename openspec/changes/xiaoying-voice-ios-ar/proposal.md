# 小莹独立生命声音与 iOS AR 原型

## Why

小莹需要从“播放声音”升级为拥有稳定含义、可组合且不等同于创作者本人的非人类语言。现有 Web 音效不能验证本地声音加工、空间陪伴和 AR 事件之间的关系，因此新增一个不改变 Web 行为的 iOS 原型。

## What Changes

- 增加公开的音素语义目录和创作者录音规范；原始录音只允许存放在本地私有目录。
- 增加离线处理工具入口，生成受授权的派生素材，不上传录音、不依赖云端 TTS。
- 增加可测试的音素组合、随机种子、冷却和优先级模型。
- 在 `ios/` 增加 Swift/SwiftUI + ARKit 的本地声音与空间交互骨架。
- Web 继续使用现有 `lib/creature-audio.ts`，只与 iOS 共享事件语义名称。

## Non-goals

- 完整人类对白、Android、跨会话世界地图、云端声音生成。
