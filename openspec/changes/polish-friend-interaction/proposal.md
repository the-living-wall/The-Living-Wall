# Proposal

## Why
Refs #95。正式网址收发、共同确认、刷新已由用户验收；微信首页入口不可点、声音状态矛盾，以及朋友页面信息分散妨碍后续使用。

## What Changes
- 修复首页入口点击与移动端控制区重叠，统一两处声音控件的真实播放状态。
- 生成、分享和反馈归到左侧；留言互动与一起塑造同时呈现，默认最近三条留言。
- 首次进入交流提供短暂双区引导、可重读说明；精简常驻文字并保留完整保存说明。
- 桌面左侧独立滚动、工具保持视口可见；手机精简底栏、详情浮层。小莹保持全屏活动，不改运动算法。
- 创建结果未确认时保留请求，明确重试同一份心意。

## Capabilities
### New Capabilities
- `friend-interaction-presentation`: 朋友互动的操作布局、首次引导、消息历史及异常反馈。
### Modified Capabilities
无。声音及移动端入口属于既有行为缺陷修复。

## Impact
app 首页声音/CSS、live-gift 前端、PRD、浏览器验证。无新依赖、接口、云权限、数据迁移或资源购买。
