# 基于原网页布局的赠光与共同塑造预览

Refs #76，依赖 #69 / PR #70。当前共同塑造验收入口；`prototypes/quiet-gift/` 保留为历史对话原型，不再代表最终布局。

页面壳从主线 `app/page.tsx` 复制为独立原型快照，直接导入原站 `app/globals.css`、Button、HandCamera、Creature/CreatureRenderer 及完整 CreatureAudio。声音控件保留原组件结构与行为，副本仅增加接收页 `autoStart=false` 和避免点击表单控件触发自动播放重试。生产路由和默认行为没有修改。

## 运行

仓库根目录安装锁定依赖后执行：

```sh
npx vite --config prototypes/live-gift/vite.config.mts
```

打开 http://127.0.0.1:4180/ 。仅监听本机，不是线上部署。构建命令：

```sh
npx vite build --config prototypes/live-gift/vite.config.mts
```

产物在 `output/gift-layout-preview/`，不提交。摄像头模型沿用原站资源；若本机缺资源，先运行 `npm run setup:assets`，访问摄像头始终需要用户主动点击与浏览器授权。

## 范围与边界

- 保留顶部品牌、左侧操作指引、右上状态、左下成长，以及右下声音/声音设置和摄像头/重新相遇/全屏。
- 保留“送给朋友”、意图选择、留言编辑与接收预览；接收无需确认收下。接收页可以切换两个模拟身份，回一句话并保留来回内容；仅内存演示，没有真实发送。
- 来回留言沿朋友原文向下阅读，默认显示最近两条，更早内容折叠；不使用聊天气泡或重边框。新的来回留言取代 #69 的单条可编辑回声，已提交的来回留言本轮不支持编辑或删除，原始赠言仍可返回编辑。
- 声音使用原站完整素材与互动编排，支持互动/音乐音量和署名链接。接收页默认静音，不因首次点击自动开启；用户可以主动开启。切换视角会销毁旧播放器。
- 成长存档改为本页内存 Map，不读写真实 localStorage 成长档案。刷新丢失演示数据。
- 手机创作/接收阶段暂隐藏成长卡，保留状态和操作；主页仍按原站显示。该差异用于避免遮挡，需人工验收。
- 接收页遇到长留言与回声时自然向下展开，允许页面滚动，避免文字和原有操作重叠；内容可容纳时原声音与底部按钮位置保持不变。
- 发送者找回回复与自愿主动提醒仅记入 SH-10～12 待办，本轮不实施，详见需求决策记录。
- 副本用于原型，正式集成前应抽取共享页面结构并对齐最新主线，不能把副本当作永久的新主页面。

## #76 体验顺序与管理边界

1. 首页「送给朋友」→「预览这份心意」，在朋友留言下方「回一句给朋友」，可以切换体验身份来回写。
2. 「留下这一刻」记录纪念；「一起塑造小莹」选择表现。先手动勾选交流来源，可填一句理由，不自动分析人格。
3. 选择沉静、俏皮、好奇或原样，点击试看。试看暂时收起其他界面；返回选择继续编辑，取消或 Escape 不保存。
4. 提出选择后切换体验身份；另一身份确认才生效。改选后需原提出者确认新版本。可拒绝或撤回，无催促和扣分。
5. 「一起留下的痕迹」查看来源快照和确认记录；恢复此前表现或取消纪念仍需共同确认。

本地 4179 旧预览保留作对照；4180 不同源且不读写真实成长键。刷新会清空留言与共同选择，没有 AI 调用、额外依赖、云服务或通知费用。本机两种身份只能验证流程，不能验证两个真人的授权。

管理分层：`shared-state.ts` 管共同确认与记录；`temperaments.ts` 管固定版本表现目录；`SharedExperience.tsx` 管编辑/试看；原 `Creature` 管个人陪伴基础规则。新增方案须新增版本键，不原地改旧版本语义。三套表现当前只是附加光纹、跳动碎光与探光，没有实现完整的行为性格。休息/受惊/恢复和减少动态时不绘制附加动作。

实际规范见 `openspec/changes/shared-shaping-prototype/`，产品索引 PRD CO-01～08；自动测试不能替代三种表现可辨识、审美和流程理解的人工体验验收。当前不合并、不部署。
