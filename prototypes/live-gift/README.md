# 基于原网页布局的赠光预览

Refs #69 / PR #70。当前主验收入口；`prototypes/quiet-gift/` 保留为历史对话原型，不再代表最终布局。

页面壳从主线 `app/page.tsx` 复制为独立原型快照，直接导入原站 `app/globals.css`、Button、HandCamera、Creature/CreatureRenderer 及完整 CreatureAudio。声音控件保留原组件结构与行为，副本仅增加接收页 `autoStart=false` 和避免点击表单控件触发自动播放重试。生产路由和默认行为没有修改。

## 运行

仓库根目录安装锁定依赖后执行：

```sh
npx vite --config prototypes/live-gift/vite.config.mts
```

打开 http://127.0.0.1:4179/ 。仅监听本机，不是线上部署。构建命令：

```sh
npx vite build --config prototypes/live-gift/vite.config.mts
```

产物在 `output/gift-layout-preview/`，不提交。摄像头模型沿用原站资源；若本机缺资源，先运行 `npm run setup:assets`，访问摄像头始终需要用户主动点击与浏览器授权。

## 范围与边界

- 保留顶部品牌、左侧操作指引、右上状态、左下成长，以及右下声音/声音设置和摄像头/重新相遇/全屏。
- 新增“送给朋友”入口、意图选择、留言编辑和接收预览；接收无需确认收下，回声仍仅内存演示。
- 回声与编辑入口放在朋友留言下方，用短分隔线、灰色小标签和同尺度正文形成连续阅读，保留换行。入口为“回一句给朋友”，编辑后“保存回声”；取消不会覆盖已保存内容，保存空白则清除。旁边明确提示尚未发送、刷新后清空。
- 声音使用原站完整素材与互动编排，支持互动/音乐音量和署名链接。接收页默认静音，不因首次点击自动开启；用户可以主动开启。切换视角会销毁旧播放器。
- 成长存档改为本页内存 Map，不读写真实 localStorage 成长档案。刷新丢失演示数据。
- 手机创作/接收阶段暂隐藏成长卡，保留状态和操作；主页仍按原站显示。该差异用于避免遮挡，需人工验收。
- 接收页遇到长留言与回声时自然向下展开，允许页面滚动，避免文字和原有操作重叠；内容可容纳时原声音与底部按钮位置保持不变。
- 发送者找回回复与自愿主动提醒仅记入 SH-10～12 待办，本轮不实施，详见需求决策记录。
- 副本用于原型，正式集成前应抽取共享页面结构并对齐最新主线，不能把副本当作永久的新主页面。
