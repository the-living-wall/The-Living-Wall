# 赠光原型：可用性修正

Refs #69；对应 PRD UI-01/02/03。这是独立体验原型，不是线上应用路由，不调用 API，不读写个人成长档案，不含真正分享与跨设备回声。

复用 `lib/creature.ts` 和 `lib/draw-creature.ts`，固定演示成长参数。状态文字读取引擎 phase/resting；暂停不推进状态。留言取消丢弃未保存编辑；保存后显示编辑入口。默认示例留言跟随心意变化，已保存留言不被切换覆盖。

## 构建

在仓库根目录安装锁文件依赖后执行：

```sh
node prototypes/quiet-gift/build.mjs /tmp/xiaoying-quiet-gift.html
```

构建使用锁文件中已有的 esbuild。输出为对话预览片段；若需要普通浏览器预览，可用当前可用的 visualize 渲染工具包装。片段依赖预览宿主的 Lucide 图标，普通浏览器独立嵌入时需补图标环境。正式应用集成与发布另行处理。
