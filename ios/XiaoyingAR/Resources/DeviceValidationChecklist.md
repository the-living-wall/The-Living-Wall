# iOS 真机验证清单

## 环境与隐私

- [ ] 使用支持 ARKit 的真实 iPhone/iPad；模拟器不作为通过依据。
- [ ] 首次启动只请求摄像头权限；当前原型不请求麦克风。未来接入语音输入后，另行展示麦克风用途并验证拒绝权限时的降级。
- [ ] 原始创作者录音只在本地私有目录；App Bundle 只包含已授权派生 WAV。
- [ ] 系统静音、App 静音与低音量都能生效。

## 空间与锚点

- [ ] 明亮桌面：点击放置小莹，邀请、靠近、休息流程可完成。
- [ ] 床头/卧室：固定位置后退出再进入本次会话，位置表现稳定。
- [ ] 弱光：给出可理解提示，不崩溃、不连续播放噪声。
- [ ] 快速移动手机：小莹触发受惊或安定，且有冷却，不循环打扰。
- [ ] 暂时遮挡或丢失平面：重新扫描后可恢复锚点或安静等待。

## 声音与互动

- [ ] `curiosity + invite` 可听出邀请意图。
- [ ] `comfort` 可听出安心；`startle` 可听出受惊；`refuse` 可听出拒绝。
- [ ] 同一事件连续触发时，变体、时长或音高有差异，但核心含义不变。
- [ ] 音频初始化失败时 AR 画面和手势仍可用。
- [ ] 耳机、手机扬声器、夜间低音量均无削波或刺耳感。

## 记录

每次测试记录设备型号、iOS 版本、光照、空间类型、事件、是否成功、声音是否打扰，以及录屏/日志路径。不得记录或上传未授权的原始声音。
