本轮已选用用户提供的本地原始候选：`XY-B1-scale.wav` 作为鳞片碎响；快速移动候选已按验收意见移除，不再接入网站。B2 擦过候选未接入网站。来源/许可记录在 `public/audio/credits.html`。

受惊/转场使用用户提供的原创候选 C（`小莹受惊转场_原创候选C.wav`），不再复用鳞片素材；网站内文件为 `public/audio/startle.wav`。

## 发声依据

| 互动/形态事件 | 声音决定 | 意义与边界 |
| --- | --- | --- |
| 独处、普通明暗呼吸、缓慢旋转 | 安静 | 不为每帧动画或每次呼吸配声 |
| 观察、试探、靠近 | 默认安静 | 避免状态抖动反复发声；视觉足以回应 |
| 手首次进入可接受接触区 | 一次轻短触碰 | 确认感知；1.5 秒冷却，悬停不重复；屏幕区域重合不代表真实触墙 |
| 连续有效抚摸 | 核心短回应 → 低频呼噜床（随享受状态持续）→ 深度享受翻动 | 呼噜使用长循环声床，离开享受状态时平滑淡出；固定序列是本轮基线，不等于完整语言体系 |
| 身体快速转向 | 动作起点一小段鳞片 | 角速度从低于阈值跨入快速时触发；同一连续旋转至少间隔 1.4 秒，抚摸中的低频呼噜不被鳞片声打断 |
| 受惊收缩、碎片散开 | 一次更明确的鳞片 | 可以抢占；仍限时，不在持续警惕期间重复 |
| 停止充分抚摸、身体放松 | 一次短舒气候选 | 0.8 秒，只有已享受互动才触发，不延迟排队、不变成招呼 |
| 疲倦进入休息 | 独立低声呼吸候选 | 2.4 秒，仅进入休息一次，不复用猫呼噜 |
| 平复、寻找、邀约 | 本轮安静 | 后续试听核心轻问候；尊重“无触碰基本安静”，不默认自动呼叫 |
| 成长变色/阶段跨越 | 本轮安静 | 后续一次稀有、很轻的泛音展开；不能让持续变色循环配乐 |

## 当前每个音频的精确触发条件

以下条件以 `lib/sound-state.ts` 的状态机为准；“有效抚摸”指小莹已经判定 `stroked = true`，不是单纯悬停或指针经过。

| 音频 | 触发条件 | 不会触发的情况 / 备注 |
| --- | --- | --- |
| 背景音乐（`kalimba.mp3`） | 声音系统激活且浏览器允许自动播放后循环播放；用户可单独调背景音乐音量 | 鼠标离开网页不暂停；页面真正隐藏时暂停，返回后尝试恢复；关闭声音时停止 |
| 呼吸（合成 `rest`） | `resting` 从 false 进入 true 时播放一次，约 2.4 秒 | 普通独处、普通明暗呼吸、鼠标移动不会触发；保持休息状态不会循环 |
| 接触回应（`touch.mp3`） | 手首次进入可接受接触区，或一次有效抚摸序列首次建立时播放；有 1.5 秒接触冷却 | 悬停不重复；离开身体或核心信任门槛未通过不算有效接触 |
| 心 / 口回应（`voice.mp3`） | 有效抚摸开始后约 1 秒，且抚摸序列仍在继续时播放一次 | 静止、快速扫过、停止抚摸不会触发；短回应之间受序列间隔限制 |
| 抚摸享受 / 咕噜（`purr.mp3`） | 有效抚摸持续约 4 秒，且 `enjoyment > 0.45` 时进入；之后作为低频循环声床持续到享受状态结束 | 不会由悬停触发；快速移动不会再重置计时；停止抚摸、受惊或进入翻动收尾时淡出 |
| 鳞片碎响（`scales.wav`） | 小莹自身朝向角速度从慢跨入快速（约 `0.65 rad/s` 起始阈值）时触发一次；同一连续旋转至少间隔 1.4 秒，身体声总冷却 1.8 秒 | 缓慢旋转、每帧呼吸、普通状态切换不会触发；不会停止持续咕噜声 |
| 快速旋转收尾（`roll.mp3`） | 深度有效抚摸持续约 8 秒且 `enjoyment > 0.65`，在咕噜阶段之后播放一次 | 不是普通旋转声；播放前会让咕噜床平滑结束 |
| 好奇伸手（合成 `curiosity`） | 页面从非触摸状态进入 `probe` 或 `invite` 阶段时播放一次 | 不因每帧状态重复；没有真实接触时才作为好奇提示 |
| 受惊 / 转场（`startle.wav`） | `alarm` 从低于 0.1 跨到大于等于 0.1 的瞬间播放一次 | `frightCount` 增加、持续警惕、恢复阶段不会重复触发；可抢占当前普通声音 |
| 满足收尾（合成 `settle`） | 已完成咕噜阶段后，充分抚摸停止且之前享受度足够时播放一次约 0.8 秒舒气 | 轻触、未进入享受、普通离开不会触发；不排队延迟播放 |

## 声音层次与下一批素材

身体：短薄鳞片（0.2–0.4 秒），与连续沙沙摩擦区分；波纹可有很轻的空气掠过，但不能每条波纹都响。
核心：需要各自录制/制作的好奇短音、愉悦短音、满足收尾，保持同一生物音色。不是把同一文件变调后称为三种新声音。
关系：接触确认最轻，亲近回应更温暖，受惊短而清楚，离开有余韵；充分留白。

先修触发密度，再评价音色是否过亮。2800Hz 是低通截止值，不能仅凭这个值判断素材刺耳。测试版把转动鳞片缩短至 0.35 秒并降低音量，受惊另设 0.65 秒；不做随机大幅变调。呼噜原始平均响度约比其他片段高 10 dB，播放增益由 0.38 降为 0.17，时长由 3 秒缩为 2.8 秒。

独立呼吸与舒气暂不采用雪声，也暂不替换为新的外部素材；当前仅保留实验候选，等新的呼吸方向确定后再接入。好奇 B 已改为原创合成：三个不等间隔的核心短脉冲，带轻微噪声和不规则音高变化，不模仿真实动物。原音频全部保留。声音设置里提供逐段试听，不要求先触发完整行为。

## 验收

- 长时间快速转向不周期播放鳞片，缓慢旋转无声。
- 转向不能清空正在进行的抚摸回应；受惊仍可抢占。
- 初次接触一次轻响，静止不进入愉悦阶段。
- 休息使用独立呼吸；普通独处无声。
- 深度享受后停止可舒气；轻触离开不舒气；不积累过期回应。
- 默认静音、后台关闭、无麦克风、成长规则保持原样。
- 自动化检查与真人音色验收分别记录；候选不视为已认可音色。
