# 小莹声音实验（AU-01 / #59 / #61）

## 2026-09-23 本地修复版

基于用户指定的 7faf764 对比实验。分支 `livehighhigh/61-sound-reachability`，未合并、未推送、未部署；不同于生产版本。原受惊行为阈值、成长和有效抚摸判定保持原样。

| 声音 | 当前素材与触发 | 限制 |
| --- | --- | --- |
| 背景音乐 | 原 `kalimba.mp3`，保留原开关、音乐音量和可见性逻辑 | 浏览器自动播放策略仍适用 |
| 呼吸 | 现有合成声；初始连续独处约 10 秒，之后至少间隔 18 秒；互动后安静至少 30 秒；进入疲倦休息也响一次 | 不按每次画面呼吸播放；通道忙则等到仍安静时再播 |
| 接触回应 | `touch.mp3`，首次有效接触 | 1.5 秒冷却，静止不反复响 |
| 心/口回应 | `voice.mp3`，有效抚摸约 1 秒后 | 独立于身体声，短通道忙则保持有效回应，离开不补播 |
| 抚摸享受 | `purr.mp3`，有效抚摸且享受度 >0.45，与界面一致 | 独立通道；接触区内 0.8 秒换向停顿可保留，离开、受惊或休息结束 |
| 鳞片碎响 | 恢复旧 `scales.mp3`，与 1030a02/745f4e5 文件哈希相同；0.6 倍速、最多 1.2 秒、增益 0.18 | 有人在场且朝向角速度 >0.65 rad/s；至少间隔 1.4 秒，初始无人朝向调整不响 |
| 快速旋转 | `roll.mp3`，朝向角速度 >1.8 rad/s 持续 0.35 秒 | 不再要求抚摸 8 秒；2.5 秒冷却；替换同一身体通道鳞片，不截断核心或呼噜 |
| 快速移动 | 恢复 `move.mp3`，历史 DJT4NN3R whoosh，原速前 1 秒 | 自身位移速度由低跨过 0.14；1.2 秒冷却；受惊后真实后退也可触发 |
| 好奇伸手 | 现有原创 B；进入 probe/invite 且未有效抚摸 | 静止接触不阻止；短通道忙最多等待 1 秒，过期/离开不补播 |
| 受惊/转场 | 保留原创 C `startle.wav` | alarm 首次越过 0.1 时一次，清空其他通道，不改受惊阈值 |
| 满足舒气 | 原合成 settle，享受结束且还有余韵时 | 一次短声，不排队招呼 |

设置保留“关闭声音”和“声音设置”，目录增加快速移动，共九个可试听名称；舒气是内部收尾事件。试听暂停自动互动发声至片段结束，呼噜试听有限时长，避免无限循环或被当前状态立刻截断。正式互动的呼噜可持续。

原 `scales.wav` 保留，但不在修复版播放。音源出处见 `public/audio/credits.html`。本轮不是制作新的音色，而是恢复原素材并修正触发和混音。

## 验证与边界

- 规则测试覆盖忙碌重试、三类声音同帧、角度跨越、休息、受惊、静止不享受、离开不补播；真实 Creature 输入验证享受与文字同步、独处呼吸。
- 本地 `/tests/fixtures/sound-reachability.html` 检查真实 Web Audio 解码、单独波形、慢抚、并行动作、停止；合成动作不是摄像头/实体触摸验收。
- 三历史节点使用相同当前 Creature 轨迹做调度比较，不冒充三个完整历史网页或生产实测。
- 音色审美和手机真人听感待用户试听；不会因为波形非零而标记“好听”。
- 发布之前需从最新 main 整合、复验并完成 PR/CI；本地实验不代表发布。
