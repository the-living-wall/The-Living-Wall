## 要交付的体验

在现有 thelivingwall.cn 中加入朋友互动：给具体朋友留一份心意，通过邀请链接进入，免注册来回留言，主动选择共同片段并由双方确认塑造小莹。个人独处陪伴仍是独立模块，不上传个人成长档案，不按消息数量、在线时长或抚摸次数奖励共同成长，不要求同时在线。

## 首版功能与所需资源

1. **免注册、双方权限分开**：不填手机号、密码或注册账号；发送者与接收者各持独立随机凭证，称呼不认证身份。需要浏览器本地存储及后台权限校验。采用 SDK 路径时还使用 CloudBase 匿名会话；这是该接入方式的技术会话，不等于强制用户注册。已上线的 HTTP 测试路径使用业务凭证，不以平台匿名登录为前提。
2. **创作专属心意**：同一区域选择开头、编辑留言、填写“给谁”和落款；修改过的正文不随选项覆盖。需要现有前端与数据库中的正文/称呼字段，不需要 AI。称呼最长 20 字，未填使用角色称呼。
3. **分享和主动接受**：一份心意一个固定 ID 和交流地址；邀请附带认领凭证，并与发送者管理凭证分开。复制后由用户粘贴到微信等渠道；每条回复不新建 URL。需要稳定 HTTPS 页面、创建/认领接口及邀请记录。打开链接不自动认领，首次明确接受者绑定浏览器；不宣称验证了收件人真实身份。
4. **持续来回留言**：原赠言与回复放在连续对话里，标明双方称呼；只有后台确认保存才显示成功。需要消息云函数、文档数据库及页面可见时每 3 秒同步。首版无需单独购买即时通信服务；同步请求仍消耗额度。离开网页后不主动推送。
5. **共同塑造与共同记录**：手选对话片段，默认保留原表现；也可选择沉静、俏皮、好奇。双方明确确认同一版本后保存。支持改选、拒绝、撤回、恢复和取消纪念；改名不改历史署名，取消纪念不删除对话或自动撤销形态。需要现有规则代码、版本化表现配方和数据库事务，不需要模型推断性格或亲密度。
6. **回来继续聊、失败可恢复**：同一浏览器能找回已保存心意，刷新后保留；断线/超时保留输入，重试不重复生成或发送，冲突需明确处理。需要浏览器凭证/待发草稿、后台操作 ID 和版本校验。换浏览器或清理站点数据后暂不承诺恢复身份。
7. **保存期限、删除和限制**：当前测试约定创建后 7 天到期，留言不续期；发送者可删除整份心意。需要数据库有效期检查、定时清理函数、容量/频率限制和费用监测。活动库到期拒绝及两个清理样本已通过；平台备份和响应日志保留仍待核实，不能声称所有副本立即消失。
8. **小莹画面、触摸和声音**：复用现有渲染与声音资源，接收者主动开启声音；所选表现普通互动中持续可见，受惊等状态按规格暂缓附加运动。需要现有网页、静态素材及用户设备，无需为此上传摄像头/触摸轨迹，也没有录制并发送语音功能。

这些点中，免注册收发、共同规则和界面已在实施分支/独立测试站有不同程度验证；不代表现有正式主站已经具备整个朋友模块。

- **数据库中保存的不只有消息**：心意正文、称呼、双方凭证散列、邀请认领状态、消息、共同提议/记录、表现版本、操作去重、到期和配额数据；不存个人成长档案。
- **仍须完成的配置/工程**：现有主站到后台的接入、实际调用权限、最终来源/HTTPS/首访邀请与响应头、发布及回退；这些不等于必须购买新资源。
- **首版不需要作为新增采购项**：短信/邮件服务、小程序服务、AI 模型、专用即时通信产品、新的独立云服务器或第二套数据库。已有套餐仍有函数、读写、存储、流量及会话等用量；未核实费用上限，不承诺零成本或无限额度。
- **OPA 不是已证明的前提**：此前为统一收紧访客访问提出环境级 OPA 策略，但尚未证明现有函数权限、安全来源和其他资源规则不足。当前建议先只读审查最小权限路径及具体缺口，不把“等用户同意切换 OPA”当成唯一下一步，不绕过自动审批拒绝。
- **备案/固定 IP/六个月续费**：此前属于另一条 CloudBase 自定义域名与备案资源路线，已暂停，不当作保存聊天记录的通用采购前提。最终业务和接入的合规要求另按真实方案核实，不作普遍豁免结论。
