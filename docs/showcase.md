# Showcase 展示控制台

公开站点的展示控制台位于 `/showcase`，用于向访客演示小莹在不同成长阶段、亲密度和信任值下的视觉状态。它是一个可重复的演示入口，不是正式站点的用户档案编辑器。

## 可调节内容

- **成长**：0–100%，直接影响成长阶段和生命形态。
- **亲密度**：0–100%，用于展示陪伴关系的亲密变化。
- **当前信任**：0–100%，用于展示信任相关的视觉反馈。
- **阶段预设**：初生白光（0%）、青痕萌发（15%）、流彩舒展（35%）、亲密共生（65%）、成熟光体（85%）。预设会同时设置成长、亲密度和信任值，便于快速比较完整阶段。
- **播放完整成长**：从 0% 逐步播放到 100%。
- **恢复初始**：把三个控制值都恢复为 0%。

## 数据边界

控制台只更新当前页面内的演示对象和画布，不调用正式站点的成长记录写入逻辑，也不改变用户在 `/` 的真实档案。刷新或离开页面后，演示状态可重新从初始值开始；正式网站的成长与亲密度仍由正式交互和档案规则负责。

## 验收重点

桌面端应能看见画布、当前阶段说明、五个阶段预设、三个滑杆和操作按钮；手机窄屏下控制台应保持可读、可操作，且不出现横向溢出。验收记录见 [`docs/evidence/showcase/2026-09-22-browser-qa.md`](evidence/showcase/2026-09-22-browser-qa.md)。
