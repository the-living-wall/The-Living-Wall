# 小莹声音录音与隐私规范

## 录音

- 48 kHz、24-bit、单声道 WAV；安静、无混响房间，固定麦克风距离。
- 录制 `curiosity`、`invite`、`comfort`、`refuse`、`startle`、`remember`、`sleep`、`play` 八类表达，每类 5–8 个版本。
- 每段 1–4 秒，只录元音、气息和短音节，不录完整对白。
- 文件名建议为 `<phoneme>_<variant>_<take>.wav`，并在私有 manifest 中记录授权、日期和删除请求。

## 隐私边界

原始录音和未处理的中间文件必须位于仓库外的私有目录，不能提交 Git、上传云端或写入应用日志。公开仓库只保存本规范、语义目录和明确经过授权的派生资源。若未来使用云端模型，必须另行取得上传、供应商、费用和删除授权。

## 听感目标

保留创作者的气息、共鸣和温度，但通过短片段、变形、空气层和颗粒层避免听起来像成年女性在说完整句子。
