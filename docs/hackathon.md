# The Living Wall · 小莹：报名材料草稿

## 一句话
养在墙上的抽象光生命：通过抚摸建立关系，让陪伴逐渐长成呼吸、形态和颜色。

## 项目简介
小莹探索一种不依赖对话框的数字陪伴方式。参与者通过停留、缓慢抚摸和移动，与程序生成的小莹建立关系。它会观察、试探、靠近、邀约，也会受惊和休息；有效陪伴推动它从白光逐渐长大、显现彩色光泽。当前已完成浏览器原型，支持鼠标、触摸与摄像头单手追踪，并实现本机成长保存。下一阶段将结合已采购的深度相机与投影方案，在普通墙面验证无框抚摸互动。

## 实现边界
- 已实现：手部视觉追踪、规则驱动的行为模型、呼吸与分区抚摸、成长保存、纯画面输出。
- 待实现：真实深度接触判断、墙面与投影校准、实体装置的延迟及遮挡验证。
- 尚未使用：大语言模型、人物身份识别、跨设备记忆。
- 如赛事要求现场从零开发或限制已有项目，请如实申报这份已有原型，并以赛事规则确定现场开发范围。本文件不是报名资格结论。

## 90 秒演示
1. 0–15 秒：独处呼吸，介绍“把陪伴长成光”。
2. 15–35 秒：鼠标或手缓慢靠近，观察与试探。
3. 35–55 秒：轻柔抚摸主体，看舒展、靠近与停手余韵。
4. 55–70 秒：快速挥动，展示惊扰与谨慎恢复。
5. 70–90 秒：说明本机成长、硬件已采购，以及下一步墙面接触验证。不要把屏幕模拟演示称为已完成实体触摸。
