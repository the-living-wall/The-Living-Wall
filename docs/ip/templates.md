# 知识产权工作模板

填写后的材料仅保存在受控位置。不要在公开 PR 填写个人资料、合同或新技术。所有“待核实”应指定负责人及复核日。

## 1. 公开证据记录（每个事件一份）

- 事件编号、渠道、链接/本地证据位置：
- 实际公开时间及其证明；若只有提交日期，明确注明：
- 当时访问条件（公开、限定受众、保密协议、未知）：
- 对应提交/构建号、公开文件或视频时间码：
- 具体可获知的技术内容；仅能看到的效果：
- 未知项、补证负责人、期限、代理师意见：
- 原始证据文件 SHA-256、保存时间、访问权限：

## 2. 权属与许可记录

- 贡献模块、贡献人及实际创造性贡献说明：
- 是否涉及劳动关系、单位任务、单位资源或委托研发：
- 合同位置、共同申请/转让约定、待确认事项：
- 申请人拟定及依据（不能仅凭仓库拥有者推定）：
- 每个代码包/SDK/模型/图片/音频的来源、准确版本、许可证原文、商用及再分发条件、NOTICE 要求：
- 不明来源素材的替换方案、负责人和期限：
- 仅在受控位置保存签署文件和身份材料。

## 3. 候选与正式检索交接

- 候选编号、PRD 编号、技术问题、已实现/规划状态：
- 商业路径、竞争者为何需要该技术、如何发现其使用：
- 最近似文献编号、优先权日/公开日、原文链接、相关权利要求/段落：
- 技术特征逐项对应；本方案具体不同点及技术效果证据：
- 已公开范围、可能的绕开实现、保密替代方案：
- 查询词、数据库、检索日期、分类号、同族扩展和引用追踪记录：
- 结论：继续/暂缓/放弃；理由、代理师、复核日期：
- 不把搜索结果缺少命中写成新颖性结论；不把摘要比较写成侵权分析。

## 4. 技术交底

- 标题、版本、贡献人、完成日期、保密接收方：
- 技术问题及最接近已有方法：
- 系统组成、输入/输出、坐标系、单位、时序及流程图：
- 必需步骤、参数含义及确定方式、异常和失效处理：
- 至少一项足以实施的完整例子；可替代组件/步骤：
- 与已有方法的具体区别；每项效果对应的实验编号：
- 尚未实现的部分及其可实施依据，禁止填入虚构实测：
- 已公开情况与证据编号；代理师待问问题：

## 5. 比较实验协议与记录

先登记协议版本、设备/固件/SDK、代码 SHA、输入数据版本、场景范围、判据、重复次数及失败计数方式。基线和候选使用同一采集输入或匹配条件；调参数据与最终测试数据分离。

### 接触识别

- 基线：固定距离阈值；候选：待实际实现后填写。
- 真值：独立侧视录像/接触传感器及时间同步，不用待测算法自身作真值。
- 条件：悬停、慢抚、快速扫过、抬手、遮挡、空洞、不同墙面与设备角度；每种条件初始至少 30 次事件，正式样本量由现场预试验确定并锁定。
- 记录误触事件/非接触试次、漏检事件/接触试次、触发及抬手延迟中位数与 P95（毫秒）；超时/无输出独立报告，不删除失败试次。
- 改善目标在测试前由负责人确认；至少一项目标改善且其余关键指标未超过预定退化阈值，才支持对应技术效果。

### 投影校准

- 基线：人工四点校准；统一投影面积、分辨率及相机摆位。
- 使用不参与拟合的检验点；记录像素误差。只有现场有可靠长度标尺时才报告毫米误差。
- 覆盖平移、旋转、重启、遮挡；每种初始至少 10 次重新部署；报告校准耗时、误差中位数/P95、恢复耗时、失败率。

### 互动渲染

- 基线与候选固定设备、浏览器、分辨率、DPR、粒子数和输入轨迹；包含稳定输入、抖动、输入丢失及多效果叠加。
- 每场景预热 10 秒，测量 60 秒、重复 5 次；同时报告绘制耗时和完整帧间隔中位数/P95，二者不可混同。
- 单独记录输入到呈现延迟与指定静止区间的位置抖动；固定采样及度量定义后再比较。录屏开销单独注明。

每次记录：实际样本数、原始数据位置及哈希、排除项和理由、结果、失败原因、执行人、复核人。模拟通过不替代真实设备验收。

## 6. 代理询价草稿（尚未发送）

拟就交互投影相关技术进行申请前评估。请提供相关领域经验及以下分项报价：保密与冲突核查、公开风险审查、中外专利/论文检索、书面可专利性意见、撰写与附图、官方费用、审查答复次数与额外收费、复审、维护及海外翻译/申请费用。请说明同族和法律状态核验是否包括、FTO 是否另计、交付时间、负责代理师及完整文件交付方式。签署保密安排并完成权属核查后再提供未公开交底。

比选记录：机构及代理师资质核验、类似案件、服务范围、含税总价及不含项目、付款节点、选择理由。未经项目负责人确认，不发送材料、不签约、不付款。

## 7. 申请与海外期限台账

- 申请类型、申请号、申请人、实际申请日、最早优先权日及回执：
- 目标市场、代理师核定的优先权期限、境外路径与费用：
- 国内完成情况、保密审查请求及结果：
- 如走 PCT：国际申请日、各目标国家阶段期限及其依据；PCT 不是全球授权。
- 提前 90/60/30 天的内部决策节点、责任人和代理复核日：
- 受理、公开、实审请求、答复、授权/缴费期限逐项登记；无实际申请日不得填写虚构到期日。
- 商标检索/申请、版权证据、许可审查、上市前 FTO 的负责人及状态：
