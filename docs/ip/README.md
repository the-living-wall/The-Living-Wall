# 商业化知识产权准备

关联 Issue [#28](https://github.com/3013038780-design/The-Living-Wall/issues/28)。本目录只保存通用流程和空白模板。无应用行为变化，PRD 未改。

目标路径：家庭消费硬件及软件/内容授权；先低成本评估、中国精选申请，保留海外选择。申请数量与预算须经过检索再决定，不以数量作为验收。

## 使用与保密边界

- 将 [工作模板](templates.md) 复制到项目负责人指定的受控存储后填写。不得将技术交底、权属合同、身份资料、未公开设计或填好的评估结论提交到公开仓库、Issue 或 PR。
- Git 忽略只防止通常的误提交，不是加密或访问控制。不要强制添加本地材料；项目所在同步盘的访问权限和备份由负责人核实。
- 每项结论注明来源、版本、检查日期、已知与待核实项。提交日期不是首次公开日期；未合并方案不是线上能力；实验结果不是授权保证。
- 现有硬件研发先核查 Issue #25，避免重复立项；其接触候选不等于实际物理接触证明。

## 90 天执行与验收

以项目负责人确认启动日为 D1；本次准备启动记录为 2026-09-17。日期按第 N 天 = D1 + N - 1 计算，计划窗口为 2026-09-17 至 2026-12-15。申请法定期限另以代理师核定的实际日期计算。

1. **D1–7 / 9 月 17–23 日：公开与权属。** 软件负责人整理版本和公开内容，项目负责人补首次上线、视频、赛事与合同证据。交付公开时间线及权属记录；缺证据必须标为待核实，由代理师评估影响。不能因缺证据就写“未公开”。
2. **D8–21 / 9 月 24 日–10 月 7 日：检索与选择。** 代理师负责正式检索，项目负责人确认预算。对接触识别、投影校准及互动渲染分别比较最近似方案、具体差异、可取证性和绕开成本。交付书面检索意见与分项报价；至少一项达到“有可实施差异、公开风险可接受、有商业价值”才进入申请准备。
3. **D22–56 / 10 月 8 日–11 月 11 日：交底与实验。** 软件/硬件负责人分别提供实现和实测，代理师审阅交底充分性。交付流程图、替代实现、基线对比和原始记录。先固定测试方法与判据，再采集数据；失败、空洞和超时也计入结果。
4. **D57–84 / 11 月 12 日–12 月 9 日：申请。** 项目负责人确认申请人、预算和目标市场；代理师提交达到条件的文件。优先一件核心发明，第二件需独立价值。验收提交回执及完整文件，不把受理写成授权。
5. **D85–90 / 12 月 10–15 日：归档与后续。** 保存申请号、申请日、期限及责任人；检查新公开内容是否覆盖于申请。条件未达成时记录继续研发或放弃理由，不为了时间表仓促申请。

## 决策规则

- 发明候选关联 PRD IN-03/HW-01、HW-02、VI-01/FX-01～03，但功能编号不意味着存在可专利创新。
- 真实接触和校准需现场证据；渲染需性能/稳定性证据。不能把普通深度阈值、四点校准、弹簧或缓存本身当作独创贡献。
- 设备结构和外观在自有设计明确后评估；GUI 适格性由代理师判断。体验规则本身不作为默认主申请方向。
- 每一候选记录商业必要性、差异证据、公开风险、侵权取证难度、容易被替代的方式和全周期费用。任一关键证据不足时保留待定，不用总分掩盖风险。
- 新研发按独立 Issue → 分支 → PR 流程推进。公开任务只写问题和验收，不提前披露未申请的技术细节。

## 法律依据与商业配套

以下来源于 2026-09-17 核查，正式提交前由代理师再次确认适用规则。

- [专利法](https://www.cnipa.gov.cn/art/2020/11/23/art_97_155167.html)：第 22～24 条涉及新颖性等条件及有限的公开例外。普通自主上线不能自动享受六个月宽限期。发明/实用新型与外观设计涉及不同优先权期限（第 29 条）。
- [2026 年生效的审查指南修改](https://www.cnipa.gov.cn/art/2025/11/14/art_99_202568.html)：算法相关申请需具体技术问题、技术手段和技术效果。
- [GUI 申请指引](https://www.cnipa.gov.cn/art/2025/12/5/art_66_202950.html)：界面外观应单独评估保护条件。
- [向外国申请专利保密审查](https://www.cnipa.gov.cn/art/2020/5/26/art_701_14.html)：在中国完成的发明/实用新型向外国申请，须核查事先保密审查要求。

上市前另做目标市场自由实施（FTO）分析，核对有效权利要求、法律状态、同族和最终产品；初步检索不替代 FTO。同步整理商标候选、代码及视觉权属、组件和模型许可、SDK 商用条款。取得自己的专利不等于可以不受他人专利限制地销售。
