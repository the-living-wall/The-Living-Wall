## 更改

- 赠言和后续留言归入“我们的对话”，按原顺序展示；最近四条直接可见，更早内容仍在同一区域按需展开。原文字不重复放在标题下。
- 分享、心意管理及保存期限放入朋友页右下辅助区，期限以一行小字显示。窄屏自然下排；原声音控件保留。
- 自动复制失败才渲染完整链接，输入框自动选中；成功复制后移除备用输入，不同时提供两个常驻入口。
- 主页不渲染具体心意管理或期限，仅有可点击的“我的心意”找回入口；修复主页 guide 的 pointer-events:none 对交互内容的影响。
