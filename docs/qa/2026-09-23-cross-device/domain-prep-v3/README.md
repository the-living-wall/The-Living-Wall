## 后续顺序与边界

1. 用户决定是否按当前 CloudBase 方案办理备案；先明确个人或企业主体（不在聊天收集证件、住址或身份证号）。
2. 续费涉及支出，需确认金额和用途后进入支付；云托管另需确认条款及实际费用，不将备案查询授权扩展为付费或开通授权。
3. 有效期和固定 IP 满足后，由用户在腾讯云提交真实备案材料并完成人脸/短信等身份步骤；Codex 可帮助准备非敏感网站说明，未经授权不提交申请。
4. 备案成功后配置独立朋友子域名、HTTPS、同源 /api 与静态安全响应头，再补首次邀请和最终来源回归。当前主域 DNS、生产站和测试路由未改。
5. 同时继续处理 [验收清单](../PENDING-ACCEPTANCE.md) 的客户端权限、备份/日志保留等工程项；备案完成不等于所有发布条件已满足。

[CloudBase 自定义域名文档](https://docs.cloudbase.net/service/custom-domain)要求完成备案；[默认域名说明](https://docs.cloudbase.net/service/alias)将现有默认来源定位为开发测试，不能把当前“先打开首页”的绕行当作正式入口方案。
