# 小莹成长系统方案

版本：v1.0  
更新时间：2026-09-21（Asia/Shanghai）  
适用范围：行为引擎、视觉形态、颜色、声音、前端界面、互动发现和本机存档

## 0. 文件定位

这是小莹成长系统的统一规格文件。任何修改形态、颜色、声音、互动解锁、成长数值或界面反馈的工作，都应先阅读本文件，并以本文件的指标定义为准。

本文件描述产品规则和验收标准，不等于所有功能已经实现。当前实现状态仍以 GitHub 仓库代码、测试和 `docs/PRD.md` 为准。

当前基础成长规则：有效抚摸增加 `care`，`maturity = care / 1800`，每日上限为 120，缺席不退化，成长保存在本机浏览器。本文件在这套兼容基础上，把成长扩展成完整的生命、关系、形态和声音系统。

## 1. 核心体验

小莹的成长不是分数变大，而是用户逐渐发现：

1. 温柔、稳定的陪伴确实让它长大。
2. 长大以后，它不只是变大，而是更有颜色、更愿意展开、更会表达。
3. 安全感会让它更快放松、更愿意靠近、更敢撒娇和回应。
4. 它依然有边界，会疲倦、会受惊，也需要安静休息。
5. 用户不需要完成强制任务，也不会因为离开而被惩罚。

推荐成长叙事：

```text
白色、谨慎、少声 → 出现颜色、愿意回应 → 身体舒展、声音变多
→ 开始邀请、撒娇、依偎 → 成熟、稳定、有安全感的陪伴
```

## 2. 四层指标模型

“成长百分比”“亲密度”“安全感”和“当前情绪”必须分开。它们代表不同时间尺度。

| 指标 | 是否长期保存 | 是否下降 | 作用 |
|---|---:|---:|---|
| 长期成熟度 `maturity` | 是 | 永不下降 | 决定生命阶段、基础体量、颜色、声音内容解锁 |
| 长期亲密度 `affection` | 是 | 第一版不下降 | 决定重新相遇时的熟悉程度和主动靠近倾向 |
| 当前安全感 `trust` | 本轮为主 | 会波动 | 决定当前是否接受核心、靠近和亲昵回应 |
| 当前享受度 `enjoyment` | 否 | 会变化 | 决定当前舒展、满足声音和余韵 |
| 当前疲倦 `fatigue` | 否 | 会恢复 | 决定是否需要休息 |
| 当前警惕 `alarm` | 否 | 会恢复 | 决定收缩、退开和受惊声音 |

不能把所有指标合并为一条“生命值”。成熟度说明小莹长到哪里，亲密度说明关系走到哪里，安全感说明此刻是否放心。

## 3. 长期成长数值

### 3.1 范围与周期

继续使用当前兼容公式：

```ts
const MAX_CARE = 1800;
const DAILY_CARE_CAP = 120;
maturity = clamp(care / MAX_CARE, 0, 1);
```

- 理论最快约 15 天达到成熟。
- 普通体验预计约 20–30 天。
- 短试玩通常只看到局部成长，不会一次完成全部阶段。

### 3.2 有效抚摸

只有有效抚摸才增加长期成长：

```text
有效抚摸 = 身体有效范围 × 缓慢速度 × 稳定相处 × 未受惊 × 未休息 × 接触允许
```

当前阈值：

| 条件 | 阈值 |
|---|---:|
| 速度下限 | `speed > 0.025` |
| 速度上限 | `speed < 0.48` |
| 稳定相处 | `calm > 1.5 秒` |
| 警惕 | `alarm < 0.1` |
| 休息 | `resting === false` |
| 深度实验 | `contact === false` 不增长 |
| 每日上限 | `120 care` |
| 总上限 | `1800 care` |

快速扫过、静止悬停、离开、受惊、深度实验中的非接触区域和休息期间的触摸都不增加 `care`。

### 3.3 增长公式

第一版保留当前实现：

```ts
earned = Math.min(dt * enjoyment, DAILY_CARE_CAP - dailyCare);
```

大致体验速度：

| 互动质量 | `enjoyment` | 每分钟成长 |
|---|---:|---:|
| 刚开始接触 | 0.25 | 约 15 care |
| 普通缓慢抚摸 | 0.50 | 约 30 care |
| 舒服、稳定抚摸 | 0.75 | 约 45 care |
| 高质量连续抚摸 | 0.90–1.00 | 约 54–60 care |

达到每日上限后，视觉、当前情绪和声音仍可响应，但长期 `care` 不再增加。页面显示：

```text
今天它已经收下了足够多的陪伴。
现在陪它安静呼吸就好。
```

## 4. 五个永久成长阶段

阶段只升不降。受惊、疲倦、离开和休息都不会让阶段退回。

| 阶段 | `care` 区间 | 成熟度 | 名称 | 关系含义 |
|---|---:|---:|---|---|
| S0 | 0–269 | 0–14.9% | 初生白光 | 刚来到墙上，还在学习安全 |
| S1 | 270–629 | 15–34.9% | 青痕萌发 | 开始记住人的靠近 |
| S2 | 630–1169 | 35–64.9% | 流彩舒展 | 愿意展开身体回应 |
| S3 | 1170–1529 | 65–84.9% | 亲密共生 | 把人当成熟悉的存在 |
| S4 | 1530–1800 | 85–100% | 成熟光体 | 形成完整而稳定的表达 |

```ts
S0: maturity < 0.15
S1: maturity >= 0.15 && maturity < 0.35
S2: maturity >= 0.35 && maturity < 0.65
S3: maturity >= 0.65 && maturity < 0.85
S4: maturity >= 0.85
```

边界：`269 → S0`、`270 → S1`、`629 → S1`、`630 → S2`、`1169 → S2`、`1170 → S3`、`1529 → S3`、`1530 → S4`、`1800 → S4`。

旧存档只有 `care` 时，根据 `care` 自动推导当前阶段。

## 5. 形态成长

小莹始终保持碎片、波纹和中央核心的身份。变化通过体量、碎片展开、波纹层次、核心关系和光泽完成。

| 阶段 | 形态 |
|---|---|
| S0 初生白光 | `growthScale 1.00–1.06`；轮廓紧凑，碎片靠近核心，波纹短而收敛 |
| S1 青痕萌发 | `1.06–1.14`；少量外围碎片伸展，间距增加，停手后出现短余韵 |
| S2 流彩舒展 | `1.14–1.27`；形成松散环绕层，横纵伸展更清楚，波纹覆盖身体大部分 |
| S3 亲密共生 | `1.27–1.36`；形成稳定外层结构，核心、身体、外围的空间层次更明显 |
| S4 成熟光体 | `1.36–1.42`；碎片层次完整，轮廓最舒展，波纹形成较长方向性路径 |

参数必须连续插值，不能在阶段阈值处突然换模型：

| 参数 | 0% | 100% |
|---|---:|---:|
| 体量 | `1.00` | `1.42` |
| 碎片展开 | `0.10` | `1.00` |
| 波纹传播 | `0.70` | `1.25` |
| 光晕半径 | `0.85` | `1.20` |
| 外围饱和度 | `0.05` | `0.82` |
| 方向伸展增益 | `0.80` | `1.15` |
| 余韵强度 | `0.60` | `1.00` |

## 6. 颜色成长

颜色基础值由成熟度决定，实时状态只做短时叠加。核心始终保持暖白或象牙白。

| 阶段 | 碎片颜色方向 | 核心 | 光晕 |
|---|---|---|---|
| S0 | 珍珠白、冷白、冰白 | 象牙白 | 冷白 |
| S1 | 薄荷青、浅青、灰青 | 暖白 | 青白 |
| S2 | 青绿、青蓝、少量淡紫 | 暖白 | 青蓝 |
| S3 | 青蓝、蓝紫、薰衣草 | 象牙白 | 蓝紫 |
| S4 | 青蓝、紫色、少量暖色高光 | 暖白 | 青紫虹彩 |

建议基础色板：

```text
S0  #F4F7F3  #EAF2F0  core #FFF9EC
S1  #C6E8D5  #B7DCDC  core #FFF8E8
S2  #80D6BE  #83C8D8  #B8B7E3  core #FFF6DF
S3  #6CB8C9  #8599D8  #C2B5E4  core #FFF4DE
S4  #5FAFC0  #788ED2  #B49BD8  core #FFF5DF
```

状态叠加：享受提高亮度；安全提高光晕完整度；疲倦降低亮度和饱和度；受惊使核心收紧、外围变冷变暗；平复时恢复基础色；休息时低亮度、低饱和、暖白呼吸。

## 7. 声音成长

声音是成长的第二条主线：

```text
谨慎短声 → 好奇回应 → 满足和邀请 → 撒娇、依偎、求续 → 安稳丰富的成熟表达
```

声音层：呼吸、碎片声、空气波纹声、核心回应、依恋表达。

声音保持同一条声线。多样性来自音节、气息、停顿、尾音、节奏和互动因果，不能只把同一段音频变调。

### 7.1 按成熟度解锁

| 成熟度 | 解锁内容 |
|---|---|
| 0–15% | 低呼吸、谨慎碎片声、短触碰回应 |
| 15–35% | 好奇短音节、轻邀请、较明亮碎片声 |
| 35–65% | 满足轻哼、柔软核心回应、方向性邀请 |
| 65–85% | 双音节回应、停手求续、依偎呼吸 |
| 85–100% | 多样短语、撒娇组合、成熟收尾、安稳回应 |

### 7.2 声音触发阈值

注意到人：`phase` 从 `alone/search` 进入 `observe`，距离上次注意声音至少 8 秒。

开始抚摸：`stroked` 从 false 变 true，距离上次触碰声音至少 2 秒。

持续舒服抚摸：有效抚摸至少 4 秒，`enjoyment > 0.45`；S2 以上允许满足轻哼，重复间隔 6–10 秒。

深度满足：有效抚摸至少 8 秒，`enjoyment > 0.65`，`fatigue < 0.75`；S2 以上允许一次满足收尾。

停手邀约：有效抚摸结束后静止 1.2–3 秒，未受惊、未休息；S0 不触发，S1 低概率，S2 中概率，S3 较高概率，S4 高概率但仍有冷却。

重新相遇：离开超过 3.5 秒后重新进入 `observe`。成熟阶段迎接更快、更熟悉，但仍低音量、短时、克制。

休息：`fatigue >= 0.8` 时最多播放一次进入休息声，休息中每 30–60 秒低概率播放一次呼吸。

依恋通过回望、轻邀约、贴近、满足收尾和安静陪伴表达；不使用长时间哭泣、频繁催促、缺席扣成长或声音内疚提示。

### 7.3 声音候选

```ts
type VoiceVariant = {
  id: string;
  family: 'breath' | 'scale' | 'air' | 'core' | 'attachment';
  minStage: number;
  trigger: string;
  weight: number;
  cooldown: number;
  intensityRange: [number, number];
  duration: number;
  materialNote: string;
};
```

同一互动类别至少准备 3 个候选；同一候选至少间隔 20–40 秒；同一场互动不连续重复；音频失败不影响视觉和成长。呼吸 V3 可保留，B2 鳞片声、空气短拍和核心回应仍需分别听感确认。

## 8. 疲倦、休息和受惊

疲倦是即时状态，不是长期成长惩罚：

| 疲倦值 | 状态 |
|---:|---|
| `0–0.35` | 精力充足 |
| `0.35–0.60` | 动作开始变慢 |
| `0.60–0.80` | 仍可互动，但回应减少 |
| `>=0.80` | 进入休息 |
| `<=0.35` 且休息至少 8 秒 | 退出休息 |

```ts
fatigue += dt * 0.009; // 有效抚摸时
fatigue -= dt * 0.018; // 非抚摸时
```

受惊当前触发：`near && speed > 1.7 + trust * 0.6 && distance < 0.5 && cooldown === 0`。受惊提高 `alarm`、降低当前 `trust`、进入 `startle`，但不扣 `care`、`maturity` 或已解锁阶段。

恢复：`alarm > 0.38` 为 startle，`0.10 < alarm <= 0.38` 为 recover，`alarm <= 0.10` 后可回到 observe/alone。

## 9. 互动发现

发现不影响基本成长速度，不产生失败状态，也不需要每日完成：

| 发现 | 触发条件 | 结果 |
|---|---|---|
| 第一次靠近 | 完成观察 → 试探 | 解锁观察描述 |
| 温柔的方向 | 连续 5 秒缓慢横向抚摸 | 解锁方向性伸展 |
| 核心回应 | `trust > 0.45` 后触碰核心 | 解锁核心短回应 |
| 一起呼吸 | 安静停留 20 秒 | 解锁低概率呼吸变化 |
| 余韵 | 抚摸后停手 3 秒 | 解锁停手余韵 |
| 安静陪伴 | 不触摸但保持附近 30 秒 | 记录安静陪伴 |
| 熟悉的回来 | 第二次相遇 | 观察阶段更快 |
| 亲密邀约 | S2 以上停手后邀约 | 解锁轻邀约声音 |
| 依偎回应 | S3 以上稳定抚摸 | 解锁柔软双音节 |
| 成熟收尾 | S4 以上长互动 | 解锁成熟满足收尾 |

不加入连续签到、断签清零、缺席惩罚、排行榜、货币、资源或强制每日任务。

## 10. 用户界面与可理解性

用户如果只看到“成长 23%”，很可能不知道数字意味着什么。因此 UI 必须让用户看见关系正在变化，但不把小莹做成血条。

### 10.1 显示两个不同概念

推荐普通界面：

```text
青痕萌发
成长 23%
亲密度：开始熟悉
它开始记住你的靠近。
```

层级：阶段名称最大；生命描述其次；亲密度是关系反馈；成长百分比是辅助信息。

成长表示小莹自身的长期成熟，亲密度表示小莹和用户之间的关系，不能共用一条进度条。

### 10.2 亲密度映射

第一版复用现有 `affection`：

```ts
affection = clamp(affection + earned / 2400, 0, 1);
```

页面只显示词语，必要时显示整数百分比：

| `affection` | 文案 |
|---:|---|
| 0–0.19 | 初次相遇 |
| 0.20–0.44 | 开始熟悉 |
| 0.45–0.69 | 愿意靠近 |
| 0.70–1.00 | 安心相伴 |

### 10.3 即时反馈

有效抚摸不显示每次 `+1`。使用：

1. 身体舒展和颜色变亮。
2. 有效互动后低频显示“它更放心了一点”。
3. 接近阶段阈值时显示“再陪它一会儿，会出现新的颜色”。

亲密度明显上升时可以显示：

```text
亲密度 ↑  它更愿意靠近你了
```

显示 1.5–2.5 秒，同一互动至少间隔 8 秒。不能每帧刷新。

### 10.4 阶段解锁反馈

跨越 15%、35%、65%、85% 时：颜色先变化，身体舒展，碎片重新排列，波纹传播，新声音短暂回应，最后显示阶段名称和一句话。

- 视觉过渡：2–4 秒。
- 声音：最多 1.5–3 秒。
- 文案：约 3 秒后淡出。
- 不暂停互动、不遮挡主体。
- 每个阶段只提示一次。

### 10.5 默认显示和开发诊断

普通用户显示：当前阶段、成长百分比、亲密度词语、阶段描述、休息/受惊/阶段切换提示。

普通用户隐藏：`alarm`、`fatigue` 精确值、每次抚摸增加多少 `care`、内部阈值和声音候选 ID。开发模式可显示完整诊断数据。

纯画面投影模式隐藏所有数字和文字，只保留视觉、声音和动作反馈；退出后恢复阶段、成长和亲密度信息。

## 11. 存档与接口

当前存档：

```ts
type Growth = {
  version: 1;
  care: number;
  affection: number;
  day: string;
  dailyCare: number;
};
```

建议版本 2：

```ts
type GrowthV2 = {
  version: 2;
  care: number;
  affection: number;
  day: string;
  dailyCare: number;
  unlockedStages: number[];
  unlockedExpressions: string[];
  encounterCount: number;
  calmInteractions: number;
  gentleStreak: number;
  lastStage: number;
};
```

版本 1 读取后，根据 `care` 推导当前阶段和已达阶段；新字段使用默认值，再保存为版本 2。深度实验继续使用独立成长存档。

建议接口：

```ts
export type GrowthStage = 0 | 1 | 2 | 3 | 4;
export function getGrowthStage(maturity: number): GrowthStage;
export function getGrowthStageInfo(stage: GrowthStage): GrowthStageInfo;
export function getGrowthProgressToNextStage(maturity: number): number;
```

声音状态增加 `growthStage`、`maturity`、`affection`、`trust` 和 `encounterCount`。声音导演使用阶段作为候选池门控，仍然只由行为事件触发。

## 12. 实施顺序

1. 统一成长接口：阶段类型、阈值配置、五档页面文案、旧存档推导、阶段/成长/亲密度基础 UI。
2. 视觉和颜色：阶段视觉配置、体量/碎片/波纹/光晕/颜色插值和过渡缓动。
3. 声音成长：声音阶段门控、候选轮换和冷却；逐段确认鳞片、空气、核心和依恋声音。
4. 互动发现：发现条件、本机记录、轻提示和自然解锁。
5. 完整验收：鼠标、触摸、摄像头、深度实验、纯画面、刷新、旧存档、上限、休息、受惊、音频失败和投影。

## 13. 验收标准

数值：`care = 0` 为 S0；`care = 270/630/1170/1530` 分别进入 S1/S2/S3/S4；`care = 1800` 后不再增长；每日 `dailyCare = 120` 后不再增长；静止挂机和 `contact:false` 不增长；受惊、缺席、休息不扣成长。

视觉：S0 主要为白色；S1 能看见青色萌发；S2 能看见青蓝和淡紫；S3、S4 有明显层次但不变成霓虹；所有阶段核心保留暖白身份；阶段过渡不闪烁、不跳形。

声音：S0 少且谨慎；S1 出现好奇回应；S2 出现满足和邀请；S3 出现柔软、依偎和停手求续；S4 更丰富但仍克制；不按每帧触发；同一候选不会连续重复；音频失败不影响视觉和成长。

用户理解：用户知道当前阶段；看见亲密关系在变深；理解颜色和声音为什么变化；不会把百分比误解成血条或危险值；不会因一次受惊或几天离开而觉得成长丢失。

## 14. 明确不做

多物种分支、成熟重置轮回、用户选色路线、碎片逐片收集、货币、装备、排行榜、连续签到、缺席惩罚、用哭泣制造依赖、未经单段验收就批量接入九状态声音，以及把深度实验宣称为真实墙面触摸。

## 15. 一句话验收

用户应能在一次短互动中看到即时回应，在几次相遇后听出小莹更熟悉自己，在持续陪伴后看见它从白色谨慎的碎光，逐渐变成有颜色、会舒展、会撒娇、会依偎，但仍然有边界和安静能力的成熟生命。
