## 1. 产品定位

**碎光（The Living Wall / Luma）** 是一个会呼吸、试探、享受抚摸，并随陪伴成长的抽象光生命。目标呈现是普通白墙上的无框互动投影；当前可运行的是浏览器交互原型。

- **核心体验**：走到墙前（或屏幕前），用手与光建立关系，而不是通过对话框。
- **关系参考**：类似与猫互动——观察、试探、温柔抚摸、放松靠近、玩够休息。
- **非目标（当前不宣称）**：大语言模型对话、人物身份识别、跨设备记忆、已完成的真实墙面深度触摸。

在线试玩：<https://thelivingwall.cn/>

## 4. 近期路线（软件）

1. **文档基线**（本 PR）：`docs/PRD.md` + `AGENTS.md`，双方对齐后合并。
2. **体验基线**：本机启动原型；跑测试/类型检查/静态检查/构建；人工体验靠近、抚摸、停手、惊扰、休息、成长恢复、摄像头与纯画面；记录设备、浏览器、提交与短录屏。发现问题单独建缺陷 Issue。
3. **逐项 FX-01 → FX-02 → FX-03**。
4. **按需发布**后复测核心体验；陪伴效果一轮评测后再推进粒子实验。

职责约定：产品与软件工作可由软件侧推进；原作者承担设备现场验证。硬件适配不阻塞上述软件路线。

- 摄像头模式检测的是画面重合，不是真实墙面接触。
- 自动化 12 项行为测试通过 ≠ 浏览器体验验收完成 ≠ 物理触摸已验证。
- 无框墙面投影与深度硬件已采购，但尚未完成接入与现场验证。硬件入门与名词见 [`docs/gemini-335.md`](gemini-335.md)，不改变本表功能状态。
