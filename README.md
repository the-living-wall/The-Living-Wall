# The Living Wall · 小莹

**[在线试玩 · Play the demo](https://thelivingwall.cn/)** — 无需安装或投影仪，打开后即可用鼠标互动，也可主动启用自己的摄像头。

**把陪伴长成光。一个会呼吸、试探、享受抚摸，并随陪伴成长的异次元生命体。**

The Living Wall is an experimental light companion that responds to gentle interaction with breathing, curiosity, trust and gradual growth.

小莹是掉落在墙上的异次元生命体，由碎片、波纹和中央核心组成，不是猫，也没有固定动物外形。人可以走到墙前，用手与它建立关系。它先观察你，再伸出几片光试探；温柔的抚摸让它舒展、靠近，突然的挥动让它退缩。长期陪伴让白色碎光逐渐长大，出现彩色光泽。

> 当前可运行的是浏览器交互原型。无框墙面投影是下一阶段目标；深度硬件已采购，尚未完成接入与实际墙面触摸验证。网站已部署至腾讯云，在线试玩入口见上方。

## 现在可以体验什么

- **相遇**：观察 → 试探 → 靠近 → 亲近；停留时主动邀约，离开后短暂寻找。
- **呼吸**：核心与外围依次明暗，节奏随安静、享受、受惊和休息变化。
- **抚摸**：主体、外围、核心具有不同接受条件；温柔移动带来舒展、靠近和停手后的余韵。
- **边界**：连续抚摸会疲倦，需要完整休息；连续惊扰会累积警惕。
- **成长**：有效抚摸积累体积、色彩与长期亲密度，静止挂机不成长，缺席不退化。
- **输入**：鼠标、触摸屏、方向键，以及 MediaPipe 单手掌心追踪。纯画面模式适合投影输出。

## 两分钟体验

1. 启动后，把鼠标移到小莹附近，等待它观察和试探。
2. 沿主体外围缓慢来回移动几秒，观察呼吸和朝向的变化。
3. 停手，留意余韵与邀约；快速扫过附近，观察它受惊后的返回。
4. 点击「启用摄像头」可用手掌尝试。保持完整手部可见；当前 RGB 摄像头模式以画面重合作为模拟抚摸，不检测真实墙面接触。
5. 「全屏纯画面」隐藏界面，Escape 或双击返回。「重新相遇」保留本机成长。

声音仍处于单段试听与确认阶段，尚未接入网站。目标是动作触发的稀疏身体声与核心回应；没有触碰时基本安静，只偶尔有很低的呼吸声。详见 [当前设定与实现边界](docs/PRD.md#11-当前设定与实现边界2026-09-20)。

## 本地运行

Node.js 22.13 或更新版本；推荐 Node.js 24。

```bash
npm ci
npm run setup:assets
npm run dev -- --port 3017
```

打开 http://localhost:3017 。摄像头仅在用户主动启用后访问；远程站点需要 HTTPS。

```bash
npm test
npm run typecheck
npm run lint
npm run build
```

`components/ui/**`（shadcn 生成组件）在 oxlint 中刻意豁免，说明见 [`docs/lint.md`](./docs/lint.md)。

## 算法与架构

```text
鼠标 / 触摸 / MediaPipe 手部关键点
                 ↓
位置平滑、速度估计、遮挡缓冲
                 ↓
行为状态 + 信任 / 警惕 / 享受 / 疲倦 / 成长
                 ↓
210 个碎片的弹簧运动、呼吸、形态与色彩
                 ↓
浏览器 Canvas / 投影仪
```

MediaPipe 是预训练的手部视觉模型；小莹的行为是可测试的规则与连续数值模型，没有训练新的神经网络，也没有接入大语言模型。当前不识别人脸或人物身份。

- `lib/creature.ts`：独立行为引擎及本机成长档案。
- `lib/draw-creature.ts`：程序化碎片渲染。
- `app/hand-camera.tsx`：摄像头与 MediaPipe 推理。
- `app/page.tsx`：输入、界面与生命周期。
- `tests/creature.test.ts`：12 项行为测试，包含遮挡、惊扰、余韵、成长、休息及接触门控。

## 硬件下一阶段

目标是普通白墙上的无框互动。计划使用 Orbbec Gemini 335 的 RGB＋深度数据，结合墙面平面估计和投影校准，输出接触位置与抬手信号。

行为引擎已预留可选 `contact` 字段：`false` 时可以引起注意，但不能积累抚摸享受或成长；现有屏幕输入省略该字段，继续作为模拟互动。本地开发主页面可主动开启近墙区域实验（Issue #50），使用独立成长档案；这仍不代表已确认物理接触。

同伴拉取与测试：见[完整启动与反馈说明](docs/testing/frontend-checkout.md)。普通前端只需 Node.js；本分支已包含匹配协议的深度服务源码，接相机时再单独创建 Python 3.12 虚拟环境。深度服务使用 8769 端口，前端点击“启用深度实验”。页面只接受真实相机的有效近墙区域，支持水平和垂直镜像，失联后清除输入。生产页面没有此入口或本地桥接接口。

已经接好相机和投影仪：按 [Mac 真实硬件启动指南](docs/testing/depth-hardware-startup.md)完成双终端启动、空墙校准、深度输入与投影检查；已装环境无需重复安装。移动设备、息屏断流或重启后的恢复步骤也在该指南中。

第一项验收：手沿墙画线，位置准确跟随，抬手后停止。接触阈值、遮挡、墙面光照、macOS 深度驱动及端到端延迟需实测，不能保证毫米级接触判断。

## 数据与限制

视频不录制、不上传，推理在本机浏览器运行。成长档案存于同一浏览器的 localStorage，无账户、数据库和跨设备同步；清理浏览器数据会丢失成长。

分区是近似径向区域，尚未实现逐片碰撞、多手语义或五种完整手势分类。推理运行在主线程；长时间性能和真实投影体验仍需现场测试。自动化测试通过不代表物理触摸已验证。
