# 小莹声音库：用户提供的本地版

归档来源：用户于 2026-09-20 提供的「小莹声音库_本地版.zip」。`index.html`、`使用说明.txt`、`线上素材目录.json` 按原件保存。

用 Chrome 或 Edge 打开 `index.html`。音频保存在当前浏览器 IndexedDB，可导入／导出包含音频的 JSON 备份。原包只带六段素材的名称、分类和修改备注，**没有音频原件**，首次打开为空库；素材目录不能代替完整备份。

这是独立的本地整理工具，不是主站的音频编辑器。页面的编辑功能仅修改名称、类型、阶段和备注，不进行降速、柔化或延长尾音。素材中的六阶段归类是此工具的分类，不替代主站九状态。原件授权和主站实际采用情况应分别核对，不从目录名推断。

本次归档不改变主站运行行为，不覆盖已有声音实现，也不部署这个本地工具。主站实际功能以代码和 `docs/PRD.md` 为准。
